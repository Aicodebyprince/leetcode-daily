## Purpose

This repository is a record of **40 consecutive days** of disciplined problem-solving — not just collecting accepted solutions, but building the ability to map unfamiliar problems to known data structures and algorithms.

Each solution includes:

- **Clean, accepted Python code** — readable over clever
- **Approach explanation** — *why* it works, not just *what* it does
- **Complexity analysis** — time and space tradeoffs documented

The goal: pattern recognition that transfers to real engineering problems.

## Philosophy

> **40 consecutive days** — not 40 problems in one weekend.  
> The goal of this repository is not to be a solution bank.  
> The goal is to build **pattern recognition**: the ability to look at an unfamiliar problem and identify the underlying data structure or algorithm within seconds.

```
Consistency produces pattern recognition.
Pattern recognition produces speed.
Speed on easy problems frees mental capacity for hard problems.
```
